Sollte ich in Contao 5.7 Twig-Layouts nutzen?

Twig-Layout oder FE‑Page

Verwendung Twig-Layouts - Vorteile

  • Verlagerung der gesamten Konfiguration ins Template
  • sehr flexibel
  • versionierbar z.B. auf Git
  • gut wiederverwendbar in anderen Projekten
  • neues Markup für modernes Webdesign
  • Cache-Busting für CSS und Javascript durch die Asset-Funktion

Twig-Layouts - Nachteile

  • neues Markup
    • deshalb CSS-Anpassungen notwendig
    • alternativ Template-Anpassungen notwendig (altes Markup generieren)
  • genutztes CSS und JS nicht einfach im Backend wählbar
  • noch experimentell
  • genutzte Erweiterungen sind eventuell (noch) nicht auf die Verwendung von Twig-Layouts vorbereitet

Verwendung FE-Page - Vorteile

  • kann als HTML5-Template oder Twig Template angepasst werden
  • wird in Contao 6 als Twig Template noch unterstützt
  • vertrautes Markup
  • vertraute Konfiguration
  • fast alle Einstellungen (wie z.B. CSS und Javascript) im Backend einstellbar
  • keine CSS-Anpassungen erforderlich beim Update von Contao 5.3

FE-Page - Nachteile

  • wird in Contao 6 als HTML5 definitiv wegfallen
  • unklar wie lange es in Contao 6 als Twig-Template noch verfügbar sein wird
  • Umstellung muss bei Wegfall des FE-Page-Templates zwangsweise umgestellt werden
  • Markup schon etwas angestaubt (z.B. z.T. viele für modernes CSS nicht benötigte Div-Tags)

Zusammenfassung

  • Twig-Layouts sind zukunftsfähig
  • generiertes Markup erleichtert den Einsatz von modernem CSS
  • noch experimentell, können sich also noch ändern
  • Einsatz nicht um jeden Preis
